# Änderungen

## 1.1

- App, Mac-Menü, Info-Texte, Diagramme, Meldungen, CSV, PDF und Zusammenfassung auf Deutsch und Englisch
- Sprache folgt beim ersten Start dem Mac und lässt sich jederzeit umschalten
- Sicherheitskorrektur: Objektivnamen aus präparierten Bilddateien können keinen Code mehr in der Oberfläche ausführen

*English:* The app, Mac menu, info texts, charts, messages, CSV, PDF and summary are now available in German and English. The language follows your Mac at first launch and can be switched anytime. Security fix: lens names from crafted image files can no longer run code in the interface.

## 1.0

Erste öffentliche Version.

- Auswertung von Brennweiten, Objektiven, Kameras, Blenden, ISO und Fototagen aus EXIF-Daten
- Frei wählbare Kennzahlen
- Objektiv prüfen mit bis zu drei Kandidaten
- Vergleich von Objektiven, Kameras und Zeiträumen
- Tabelle mit Excel-artigen Filtern, CSV- und PDF-Export
- Mac-App für Apple Silicon und Intel ohne Zusatzinstallation
