# Sicherheit

Brennweiten ist ein privates Freizeitprojekt ohne garantierte Reaktionszeiten.

Melde Sicherheitslücken bitte vertraulich über **Security → Report a vulnerability** in diesem Repository und nicht als öffentliches Issue.

Die App startet einen lokalen Server, der nur auf `127.0.0.1` lauscht und die Herkunft von Anfragen prüft. Besonders interessant sind daher Wege, wie eine Webseite oder eine präparierte Bilddatei auf lokale Daten zugreifen, Dateien verändern oder Code ausführen könnte.

# Security

Brennweiten is a private hobby project with no guaranteed response times.

Please report security issues confidentially through **Security → Report a vulnerability** in this repository, not as a public issue.

The app starts a local server that listens only on `127.0.0.1` and checks the origin of requests. Of particular interest are ways a website or a crafted image file could access local data, change files or execute code.
